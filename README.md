# 궤도 공장 시뮬레이터

원료를 우주 궤도로 올려 미세중력에서 한 단계를 가공하고, 다시 지구로 가져오는 "우주 제조" 과정을 브라우저에서 돌려보는 개념 시뮬레이션입니다.

**바로 보기:** https://kkaengemine.github.io/orbital-factory-sim/

## 화면 구성

1. **올리고, 가공하고, 가져오기**
   발사 → 궤도 진입 → 미세중력 가공 → 재진입 → 착륙·회수 단계를 애니메이션으로 보여줍니다. 재생/일시정지, 단계 이동, 속도 조절을 지원합니다.
   - 무인 캡슐 방식: 위성 본체에 붙은 캡슐이 자동으로 가공한 뒤 낙하산으로 사막에 착륙
   - 국제우주정거장 경유 방식: 화물선으로 올려 정거장에서 가공하고, 귀환선이 바다에 착수
2. **가공 단계: 지상 vs 미세중력**
   같은 공정을 지상(중력 있음)과 궤도(미세중력)에서 나란히 돌려 비교합니다.
   - 결정(의약품 원료, 반도체 씨앗 결정): 지상에서는 침전과 대류로 결정이 엉기고 크기가 들쭉날쭉, 궤도에서는 고르게 성장
   - 광섬유: 지상에서는 빛을 흩뜨리는 작은 결정이 더 자주 생겨, 결함 없이 팔 수 있는 길이가 줄어듦
3. **손익 계산**
   원료 무게, kg당 제품 가치, 수율, 비용 가정(임무 고정비, 올리기·가져오기 kg당 단가)을 바꾸면 임무 1회 손익과 본전이 되는 kg당 가치가 바로 계산됩니다.

## 로컬에서 열기

빌드 과정이 없는 HTML 파일 하나입니다. `index.html`을 브라우저로 열면 됩니다.

## 운송 방식·제품 추가하기

`index.html`의 `<script>` 위쪽에 있는 두 목록에 항목을 하나 더하면 화면 선택지에 바로 나타납니다.

- `SCENARIOS`: 운송 방식. 단계 목록(`stages`)과 비용 가정(`costs`)을 가집니다. 단계의 `key`는 애니메이션 종류(`launch`, `orbit`, `dock`, `process`, `undock`, `reentry`, `landing`, `splashdown`) 중 하나입니다.
- `PRODUCTS`: 제품. `mode`가 `crystal`이면 결정 성장 비교, `fiber`이면 광섬유 인출 비교 화면을 씁니다.

## 주의

- 비용 숫자는 공개 발사 가격과 업계 추정을 섞은 **대략적인 가정치**입니다. 실제 계약 가격과 다를 수 있습니다.
- 공정 애니메이션은 현상을 보여주기 위한 개념 모델이며, 실제 물성 계산이 아닙니다.
- 환율은 1달러 = 1,400원으로 가정했습니다.
